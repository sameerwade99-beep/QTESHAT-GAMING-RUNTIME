
# QTESHAT GAMING Runtime

Runtime engine for running Windows games on Android ARM64.

## Project Status

Development in progress.

## Components

- Linux ARM64 Root Filesystem
- Box64
- Wine
- DXVK
- VKD3D-Proton

## Architecture

The runtime will be downloaded and installed inside the Android application's private storage.

All runtime packages must be verified using SHA-256 checksums before installation.

## Important

No component is considered operational until it has been integrated and tested on a real Android ARM64 device.
